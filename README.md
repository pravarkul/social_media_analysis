# 📱 Social Media User Behavior Analysis

**End-to-End Data Analysis Project**  
Analyzed **1.55 million** user records to uncover what actually drives engagement on social media.

### Project Overview
This project challenges the common myth that “more time spent = more engagement.” Using Python, SQL, and Power BI, I performed data cleaning, feature engineering, advanced SQL analysis, and built an interactive dashboard to reveal real behavioral patterns between **Creators vs Consumers**, engagement segments, time buckets, and lifestyle factors.

### Problem Statement
Social media platforms assume higher screen time equals higher engagement. This analysis tests that assumption across:
- Usage duration (time buckets)
- User types (Creators vs Consumers)
- Engagement segments (Low → Power users)
- Lifestyle & demographic factors

### Tools & Technologies
- **Python**: Pandas, NumPy, Matplotlib, Seaborn (data cleaning + feature engineering)
- **SQL (MySQL)**: Joins, CTEs, Window Functions, Aggregations
- **Power BI**: Interactive dashboard with slicers and KPI cards

### Key Insights
- **Engagement is front-loaded** — scores drop sharply after the first 30 minutes.
- **Creators spend 90% more time** (260 min/day vs 137 min/day for Consumers) but show almost no engagement advantage.
- **Power users** dominate value — they have 3.4× higher engagement scores than Low users.
- **Lifestyle has minimal impact** — Healthy vs Unhealthy users show almost identical time spent and engagement.
- **More time ≠ better engagement** — Excessive usage leads to content fatigue across all segments.

### Dashboard Highlights
- **1.55M** Total Users  
- **1.64** Average Engagement Score  
- **221.18 min/day** Average Time Spent  
- **68.29%** Creators in the dataset  
- Interactive filters for country, user type, and engagement segment
